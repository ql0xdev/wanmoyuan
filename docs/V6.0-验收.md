## 文档中的取值

- 一层到九层有八次小突破，因此小突破合计约为大突破的 **64%**，连大突破合计约 **1.64 倍**；不额外收第九次费用。渡劫没有下一大境，以进入渡劫的 100000 作为费用基准，每层 8000。
- 新部位照抄同类现有基础属性：炼气级帽子气血 +18%、护手攻击 +22%、裤子减伤 +4%、鞋子移速 +5%。装备等级 ×2、品质色、词条数量与升星规则照旧。
- Windows 的实拍与脚本自检不等于 Android 真机验收；未连接 Android 手机。APK 与前版同包名同签名，可覆盖安装；想回退 V5，请在首次写档前备份原 V6 格式存档。
