## 复验与安装

- `tests/v66.gd` 使用空的 `wanmoyuan-v66-test-*` 隔离 `APPDATA`。可无头运行，截图用 `--disable-vsync --max-fps 60 --resolution 540x960 -s res://tests/v66.gd -- --shots <目录> [--fixture <旧存档>]`。
- 以后换立绘只需替换同路径的 PNG 并让 Godot 重新导入；使用透明背景 PNG 时可保留现有光环效果，不必修改场景或代码。
- APK：`6.6` / `versionCode=23`，包名 `com.wanmoyuan.demonabyss`，与 V6.0 修复包及 V6.5.1 同签名，可覆盖安装。SHA-256：`fc9960c27aa0a262cb42dad4148bae3cf4ade8a5c411c6aab4501f9c6d8f7c6b`。
- 已做 Windows 自检和 APK 验签；未连接 Android 真机。
