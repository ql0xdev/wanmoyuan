# 《万魔渊》开发设计文档 V2.0

> 本文档是 V2 版本的开发依据，给 AI 编程助手（Claude Code / Kimi Code）使用。
> 前提：V1 已完成（移动、刷怪、5 功法、升级三选一、Boss、胜负闭环、安卓导出）。
> 本文档未明确提到的功能一律不做，不要自由发挥。V1 已有系统除非本文档明确修改，否则保持不变。

---

## 1. V2 版本目标

一句话：**加入"灵石经济 + 法宝商店 + 装备合成"系统**（类似王者荣耀的局内装备），并修复 V1 遗留问题、补充基础游戏感。

玩家体验变化：打怪除了掉灵晶（经验），还会掉**灵石（货币）**；随时可打开商店购买法宝；小件法宝可合成强力成装；凑齐神装后决战魔尊。

## 2. V1 遗留修复（最先做）

- **打孔屏遮挡**：所有 UI 使用 Godot 安全区域（`DisplayServer.get_display_safe_area()`），顶部经验条、境界文字、计时器等避开摄像头挖孔和圆角区域。

## 3. 双货币体系

| 货币 | 颜色/形状 | 来源 | 用途 |
|---|---|---|---|
| 灵晶（沿用 V1） | 蓝色小晶体 | 所有怪物必掉 | 经验，攒满升级三选一选功法 |
| **灵石（新增）** | 金色菱形，比灵晶略大 | 精英/Boss 必掉，小怪概率掉 | 在商店购买法宝 |

### 灵石掉率（初版数值）

| 来源 | 掉落 |
|---|---|
| 狼妖 | 10% 概率掉 5 灵石 |
| 鸦妖 | 20% 掉 8 灵石 |
| 石傀 | 必掉 30 灵石 |
| 魔尊 | 必掉 200 灵石 |

- 灵石与灵晶一样有磁吸拾取，吸附范围共用
- 屏幕右上角显示当前灵石数量（金色图标 + 数字）

## 4. 法宝商店

- **打开方式**：屏幕右上角"商店"按钮（触屏可点），点击后**游戏暂停**，弹出商店面板；再点关闭按钮恢复
- **界面布局**（竖屏）：上半部分为商品列表（可上下滑动），每件法宝显示：图标（占位色块+名称）、效果描述、价格、当前持有数；下半部分为玩家已有的 6 个法宝格子
- **购买规则**：
  - 灵石足够且有空格子 → 点击购买，立刻生效并入格
  - 格子满（6 件）→ 禁止购买并提示"法宝栏已满"
  - **已拥有的小件在购买成装时可抵扣价格**（王者式合成：成装价格 = 合成所需小件总价，已持有的对应小件自动折算扣除，合成后小件消耗掉并释放格子）

## 5. 法宝清单（6 小件 + 6 成装，属性全部叠加生效）

### 小件（每件 150 灵石，可重复购买，同名小件效果叠加）

| 法宝 | 效果 |
|---|---|
| 铁剑 | 全部功法伤害 +10% |
| 雷符 | 全部功法冷却 -10%（上限 -40%） |
| 神行靴 | 移动速度 +10% |
| 护身符 | 生命上限 +25（并立即补 25 血） |
| 聚灵佩 | 拾取范围 +50% |
| 饮血珠 | 每次击杀回复 1 点生命 |

### 成装（由小件合成，不可直接购买，合成后占用 1 格）

| 成装 | 合成公式 | 价格 | 效果 |
|---|---|---|---|
| 青锋剑 | 铁剑 × 2 | 300 | 全伤害 +25%；御剑术飞剑数量 +1 |
| 诛仙雷剑 | 青锋剑 + 雷符 | 450 | 全伤害 +30%；雷诀落雷数量 +1 |
| 玄武甲 | 护身符 × 2 | 300 | 生命上限 +60；受伤减免 15% |
| 追云履 | 神行靴 × 2 | 300 | 移速 +25%；受击后 1.5 秒内移速额外 +30% |
| 乾坤袋 | 聚灵佩 × 2 | 300 | 拾取范围翻倍；灵石掉落量 +20% |
| 血菩提 | 饮血珠 × 2 | 300 | 击杀回血 +3；生命低于 30% 时回血效果翻倍 |

- 合成操作：在商店中，当玩家持有合成配方所需的全部小件时，对应成装亮起可点，点击后消耗小件、获得成装（不额外收灵石，价格已在购买小件时付过）；也允许灵石直接补齐差价（持有部分小件时，缺少的小件按原价折算灵石扣除）
- 成装每局每样限持 1 件

## 6. 与 V1 系统的衔接规则

- 升级三选一选功法**完全不变**（灵晶管功法，灵石管法宝，互不干扰）
- 法宝属性对功法的影响实时生效（如买了铁剑，飞剑伤害立即提升）
- Boss 战节奏不变（180 秒魔尊登场），V2 的数值设计目标：**不买装备勉强能苟活，合理买装后能和 Boss 正面一战**

## 7. 游戏感（果汁）补充

- 命中怪物飘伤害数字（白色普通，橙色暴击预留）
- 怪物死亡：缩放爆散 + 短暂白闪
- 玩家受击：屏幕轻微震动（0.15 秒）
- 购买/合成成功：音效 + 格子高亮闪一下
- 音效沿用 V1 接口：补飞剑、落雷、受击、升级、购买 5 个程序化音效

## 8. 技术要点

- 法宝用**数据驱动**：所有法宝定义写一个数据表（字典/Resource），商店和属性计算读表，加新法宝不改逻辑代码
- 属性计算集中在一个 `StatsManager`：基础值 + 法宝加成，功法释放时读取
- 商店 UI 用 CanvasLayer 实现，打开时 `get_tree().paused = true`，商店节点 `process_mode` 设为 Always
- 灵石数量、法宝持有情况需要纳入"再来一局"的重置逻辑

## 9. 开发顺序（里程碑，每步完成停下等验收）

1. **M1 修补**：打孔屏安全区域修复 + 灵石掉落/磁吸/右上角计数 UI
2. **M2 商店**：商店界面（打开/暂停/关闭/格子栏），先放铁剑一件，跑通购买流程
3. **M3 小件**：6 件小件全部实装，属性通过 StatsManager 正确生效
4. **M4 合成**：合成规则（抵扣、差价补齐、释放格子）+ 6 件成装全部实装
5. **M5 果汁**：伤害飘字、死亡爆散、受击震屏、5 个音效
6. **M6 打磨**：真机完整跑 3 局（含胜利/失败/重开），根据手感调整掉率与价格

## 10. 明确不做（V2 范围外）

- 功法进化/合体系统（V3 候选）
- 局外成长（洞府加点，V3 候选）
- 难度分级、新怪物、新 Boss、新功法
- 装备主动技能、装备出售、多存档
- 精致美术换皮、背景音乐
