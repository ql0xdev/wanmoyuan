# 《万魔渊》设计文档 V2.5 —— 3D 化迁移

> 本文档是 V2.5 版本的开发依据。目标只有一个：**把游戏从 2D 俯视角迁移为"3D 画面 + 斜 45° 固定视角"，玩法、数值、系统全部不变。**
> 这是一个纯"表现层"改造版本，严禁借机加新功能。

---

## 1. 目标与原则

- 视角：斜 45° 俯视固定视角（参考：王者荣耀、暗黑破坏神），镜头平滑跟随玩家，**不可旋转、不可缩放**
- 画面：全部场景元素改为 3D（角色、怪物、飞剑、地形），UI 保持 2D 覆盖层不变
- 逻辑：所有游戏逻辑（移动、碰撞、刷怪、伤害、功法、商店、升级）行为必须与 V2 完全一致
- 美术：全部使用占位模型（Godot 内置 CapsuleMesh / BoxMesh / SphereMesh），禁止在美术上花时间

## 2. 技术方案

### 坐标系迁移
- 原 2D 的 XY 平面逻辑 → 3D 的 XZ 平面（Y 轴为高度）
- 所有位置、速度、方向向量从 Vector2 迁移为 Vector3（y 分量恒为 0）
- 碰撞体从 CollisionShape2D 换为 CollisionShape3D，半径等数值不变

### 摄像机
- Camera3D，位置在玩家后上方，俯角约 45°，固定朝向
- 平滑跟随（lerp），参数沿用 V1 手感
- Projection 用 Perspective，FOV 50 左右（调出让手机竖屏视野合适的值）

### 场景与光照
- 地面：一个大的 PlaneMesh，深灰绿色占位材质，加少量 BoxMesh 岩石/柱子点缀场景边缘
- 光照：一盏 DirectionalLight3D（斜向下 45°，模拟天光）+ 环境光（WorldEnvironment，环境光能量 0.4 左右）
- 加一点雾效（Fog）让远处淡出，掩盖场景边缘
- 渲染器保持 Compatibility

### 模型占位对照表

| 元素 | 占位模型 | 颜色 |
|---|---|---|
| 玩家 | CapsuleMesh（高 1.6） | 青色 |
| 狼妖 | CapsuleMesh（高 1.2） | 红色 |
| 鸦妖 | SphereMesh + 悬浮（y=1.5） | 紫色 |
| 石傀 | BoxMesh（2 倍大） | 灰色 |
| 魔尊 | CapsuleMesh（高 3.5） | 黑红色 |
| 飞剑 | BoxMesh 拉长（0.1×0.1×1.2） | 白色发光材质（Emission） |
| 落雷 | 细高 CylinderMesh 瞬间出现消失 | 蓝白发光 |
| 火珠 | SphereMesh 小 | 橙色发光 |
| 灵晶 | 小八面体（PrismMesh 或压扁 Sphere） | 蓝色发光 |
| 灵石 | 小八面体 | 金色发光 |

- 发光效果：StandardMaterial3D 开 Emission 即可，不做后处理

## 3. 性能红线（手机上必须达成）

- 同屏 3D 怪物上限 **100 只**（超出部分暂停刷新，沿用对象池）
- 所有怪物共用同一网格资源，禁止每只怪单独 new Mesh
- 飞剑/法球等投射物沿用对象池
- 目标：中端安卓机 60fps，掉帧时优先砍同屏怪数量，不许砍帧率

## 4. UI 适配

- 所有 2D UI（血条、经验条、商店、结算、三选一）原样保留，继续用 CanvasLayer
- 虚拟摇杆逻辑不变
- 唯一新增：3D 场景与 UI 的层级关系确认（UI 永远在最上层）

## 5. 开发顺序（里程碑）

1. **M1 空场跑人**：3D 场景 + 地面 + 光照 + 摄像机跟随 + 玩家胶囊体移动（摇杆/键盘），手感与 V2 一致
2. **M2 怪物回归**：三种怪 + 刷怪节奏 + 追击/远程行为 + 碰撞伤害，全部在 3D 下复现
3. **M3 功法回归**：五个功法的 3D 表现（飞剑、落雷、火环、冰域、回血），升级三选一正常
4. **M4 系统回归**：灵晶/灵石拾取、商店、Boss、胜负结算全流程跑通
5. **M5 上机验收**：真机测试帧率与发热，同屏 100 怪压测

## 6. 验收标准

- 闭上眼睛（不是）——用 V2 的玩法经验玩 V2.5，**除画面外感觉不出任何差别**即为成功
- 真机 60fps，连续玩 10 分钟不烫手降频

## 7. 明确不做

- 角色动画、骨骼、贴图、粒子特效（V4 换皮时再说）
- 镜头旋转/缩放/跟随以外的任何行为
- 新怪物、新功法、新系统（那是 V3 的事）
- 地形编辑器和精美场景
