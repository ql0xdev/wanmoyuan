# 万魔渊 V5.0.1 · 返修验证

[Android APK](../android/wanmoyuan-v5.0.1-debug.apk) · [Windows x64](../.godot/v5.0.1-release/WanMoYuan.exe)

- **掉落与升级**：小怪死亡掉蓝色修为灵石，离得远时留在地上。进入拾取范围才开始磁吸，吸取完成才加修为；达到原阈值才弹三选一。妖狼、鸦妖每颗 20，石傀每颗 100，升级阈值和卡池不变。金色灵石仍按原规则掉落，用于商店和带回，不用于升级。
- **角色高度**：模型世界高度 264 → 108，底部仍贴地；镜头、碰撞体、移动和技能范围不变。

Windows 验证：[击杀后灵石在地上、修为不涨](../.godot/v5.0.1-review/返修01-击杀掉灵石但修为不涨.png) · [拾取后弹出三选一](../.godot/v5.0.1-review/返修02-拾取灵石后弹出三选一.png) · [横屏角色比例](../.godot/v5.0.1-review/返修03-横屏角色贴地.png)。另测了金色灵石只入钱包、未捡的蓝色灵石不在结算时补发。
