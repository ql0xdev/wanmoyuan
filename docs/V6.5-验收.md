## 复验和安装

- `tests/v65.gd` 使用空的 `wanmoyuan-v65-test-*` 隔离 `APPDATA`。无头可直接运行；截图用 `--disable-vsync --max-fps 60 --resolution 540x960 -s res://tests/v65.gd -- <截图目录> [旧 V7 存档路径]`。旧档路径可省略，脚本会生成等价的隔离测试档。
- APK 为 `6.5` / `versionCode=21`，`com.wanmoyuan.demonabyss`，验签证书与修复版 V6.0 一致，可覆盖安装。APK SHA-256：`9d1bb2634bea5d8ee77588f6e3747a56151e41cf4f2e3b2e40ae263d4c57b110`。
- 本次无 Android 真机连接。触控在 Windows 通过屏幕触控事件验证，APK 仅做打包、包名、版本与签名检查。
