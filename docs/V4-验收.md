# 万魔渊 V4.0 · 交付自检

基线 `36bc93d`（V3.1.4），分支 `v4`，本地标签 `v4.0`。以下对照 V4 设计文档 §8；截图为 Windows 实际游戏画面，不是 Android 截图。隔离测试会补齐灵石、推进计时、布置目标或设置固定怪物负载，不改导出包的正式数值。

## 运行与安装

- Windows x64：[WanMoYuan.exe](../.godot/v4.0-release/WanMoYuan.exe)，可直接运行；也可用 Godot 4.7.2 打开 `project.godot`，按 F5。
- Android ARM64 / ARMv7：[wanmoyuan-v4.0-debug.apk](../android/wanmoyuan-v4.0-debug.apk)，包名 `com.wanmoyuan.demonabyss`，版本 `4.0` / `10`。连手机后运行 `adb install -r .\android\wanmoyuan-v4.0-debug.apk`；不要卸载旧版来解决签名冲突。
- [全部关键截图 ZIP](../.godot/v4.0-release/V4-screenshots.zip)；也可使用下表单张查看。

### 手机复验

1. 从旧 APK 覆盖安装 V4，点「继续修行」，核对洞府、装备、功法和已通关状态，不清数据。
2. 在五层 05:00 触发兽潮与天相；将 Boss 打到 8,000 HP 或以下，留它到下一波，观察扇形弹幕和围拢的怪群同屏时的帧时间、触控响应。
3. 连续打约 10 分钟，记录机型、帧率与是否发热降频；回洞府后重启确认保存。这三项仅能用真机结论标记通过。
