# 《万魔渊》开发设计文档 V1.0

> 本文档是给 AI 编程助手（Claude Code / Kimi Code）的开发依据。
> 目标：**先做最小可玩版本（MVP）**，玩法闭环完整，美术一律占位。
> 本文档未明确提到的功能，一律不做，不要自由发挥。

---

## 1. 游戏概述

- **名称**：万魔渊
- **类型**：修仙题材 Roguelike 生存射击（"吸血鬼幸存者"类）
- **视角**：2D 俯视角
- **平台**：Android 手机（首要），PC 用于开发调试
- **一句话玩法**：玩家用虚拟摇杆控制修士走位，功法自动攻击潮水般涌来的怪物，拾取灵晶升级、三选一强化功法，存活至魔尊现身并将其斩杀即渡劫成功。

## 2. 技术栈与硬性要求

- 引擎：**Godot 4.7**（GDScript，不要用 C#）
- 渲染器：**Compatibility（兼容模式）**（项目创建时已设定，勿改）
- 分辨率基准：720×1280（竖屏），自适应缩放（Project Settings → Display → Stretch → mode: canvas_items, aspect: expand）
- 输入：必须同时支持 **虚拟摇杆（触屏）** 和 **键盘 WASD/方向键（PC 调试）**，同一套移动逻辑
- 性能：怪物/子弹/掉落物**必须使用对象池**，目标同屏 200 只怪 + 100 发子弹在骁龙中端机上 60fps
- 代码规范：每个场景一个主脚本，中文注释关键逻辑；场景、脚本命名用英文（如 `player.tscn`、`wolf_demon.gd`）
- 项目结构：
  ```
  scenes/   （场景：main, player, enemies/, skills/, ui/）
  scripts/  （通用脚本：对象池、游戏状态管理）
  assets/   （占位图形，用 ColorRect/Polygon2D 或简单色块即可）
  ```

## 3. 核心循环

```
走位躲怪 → 功法自动攻击 → 怪物死亡掉落灵晶 → 拾取灵晶攒经验
→ 升级弹出三选一功法强化（游戏暂停）→ 继续战斗 → 怪随时间变强
→ 3 分钟时 Boss"魔尊"现身 → 击杀魔尊 = 渡劫成功（胜利结算）
→ 死亡 = 渡劫失败（失败结算）→ 结算界面可"再来一局"
```

## 4. 玩家（修士）

| 属性 | 数值（初版，可调） |
|---|---|
| 生命值 | 100 |
| 移动速度 | 200 像素/秒 |
| 碰撞半径 | 16 像素 |
| 受击无敌帧 | 0.5 秒（受伤闪烁提示） |
| 初始功法 | 御剑术 Lv1 |

- 移动：摇杆/键盘方向 × 速度，无惯性，八方向即可
- 经验条在屏幕顶部，攒满立即暂停弹升级界面
- 摄像机平滑跟随玩家

## 5. 怪物

怪物从**屏幕外四周**随机位置刷出，向玩家移动。刷怪节奏随时间加快。

| 怪物 | 生命 | 速度 | 伤害 | 行为 | 出现时间 |
|---|---|---|---|---|---|
| 狼妖（近战） | 20 | 120 | 10 | 直线追击，碰到玩家造成伤害（有 1 秒攻击冷却） | 开局 |
| 鸦妖（远程） | 12 | 90 | 8 | 与玩家保持 300 像素距离，每 3 秒吐一颗法球（速度 150） | 40 秒后 |
| 石傀（精英） | 120 | 60 | 20 | 缓慢追击，体型 2 倍，死亡掉 5 颗灵晶 | 90 秒后，每 30 秒一只 |

- 刷怪频率：开局每 2 秒 1 只，每过 30 秒频率 +15%（下限 0.4 秒/只）
- 怪物之间不互相碰撞（允许重叠），只与玩家碰撞
- 怪物死亡播放简单闪烁/缩放消失动画（Tween 即可）

## 6. 灵晶与升级

- 怪物死亡掉灵晶（狼妖/鸦妖 1 颗，石傀 5 颗），灵晶 3 秒内自动飞向玩家（磁吸）
- 升级所需经验：第 1 级 5 点，之后每级 ×1.3 取整
- 升级时**暂停游戏**，屏幕中央弹三张功法卡牌，点击/按键选择后继续
- 境界显示（纯仪式感）：1 级炼气、5 级筑基、10 级金丹、15 级元婴，突破时全屏闪金光 + 大字提示"突破·筑基"

## 7. 功法系统（5 个，各 3 级）

功法自动释放，无需操作。三选一时：未拥有的显示"习得"，已拥有的显示"升级"。

| 功法 | 效果 | Lv1 → Lv3 |
|---|---|---|
| 御剑术 | 每 1 秒向最近敌人发射飞剑 | 1 把剑/伤 10 → 2 把/伤 15 → 3 把/伤 20 |
| 雷诀 | 每 3 秒随机劈落雷 | 1 道/伤 15 → 2 道/伤 22 → 3 道/伤 30（小范围） |
| 护体罡气 | 火环绕身旋转，碰到即伤 | 3 颗火珠/伤 8 → 4 颗/伤 12 → 5 颗/伤 16 |
| 冰心咒 | 以自身为中心 200 像素减速领域 | 减速 30% → 40% → 50% |
| 回春功 | 被动回血 | 每 5 秒回 3 → 每 4 秒回 5 → 每 3 秒回 8 |

- 三选一池子 = 未满级功法中随机抽 3 个；全满级则给"+20 生命上限"保底选项
- 升级界面用鼠标点击 + 触屏点按都可选中

## 8. Boss：魔尊

- 第 **180 秒**在屏幕外现身，登场时屏幕震动 + 顶部大字"魔尊现世"
- 属性：生命 800，速度 80，碰撞伤害 30
- 技能 1「魔焰冲击」：每 6 秒向玩家方向扇形发射 5 颗法球
- 技能 2「召唤」：每 15 秒召唤 4 只狼妖
- 血条显示在屏幕顶部
- 击杀魔尊 → 慢动作 0.5 秒 → 胜利结算
- Boss 存在期间小怪继续按节奏刷新

## 9. UI 与结算

- 战斗中：顶部经验条 + 境界名 + 存活计时；左上血条；Boss 出现后顶部 Boss 血条
- 虚拟摇杆：左半屏任意位置按下出现，跟随手指
- 胜利结算：「渡劫成功」+ 存活时间 + 击杀数 + 最终境界 + 「再来一局」按钮
- 失败结算：「身死道消」+ 存活时间 + 击杀数 + 「再来一局」按钮
- 开始界面（极简）：标题「万魔渊」+「开始修行」按钮
- 中文字体：用系统字体即可（Godot 默认支持系统字体回退）

## 10. 音效（占位级）

- 攻击命中：短促"叮"；升级："钟鸣"；Boss 登场：低音轰；死亡：闷响
- 可用 Godot 的 AudioStreamGenerator 程序化生成简单音效，或先留接口后补

## 11. 开发顺序（严格按里程碑执行，每步完成后停下来让人类验收）

1. **M1 能动**：主场景 + 玩家移动（摇杆+键盘）+ 摄像机跟随
2. **M2 能活**：狼妖刷出追击 + 御剑术自动攻击 + 怪物死亡掉灵晶
3. **M3 能升级**：经验条 + 三选一升级界面 + 5 个功法全部实现
4. **M4 有挑战**：鸦妖、石傀加入 + 刷怪节奏曲线 + 玩家受伤/死亡
5. **M5 有结局**：Boss + 胜负结算 + 开始界面 + 再来一局闭环
6. **M6 能上机**：Android 导出预设配置（输入、分辨率适配验证）

## 12. 明确不做（本版本范围外，不要实现）

- 装备/法宝掉落与词条系统（V2 再做）
- 局外成长、存档、多角色、多关卡
- 精致美术、粒子特效、背景音乐
- 联网、排行榜、广告
