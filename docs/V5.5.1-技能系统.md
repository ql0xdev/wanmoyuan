# 万魔渊 V5.5.1 · 当前技能与进化

这份表按 V5.5.1 的实际实现整理。伤害、范围和冷却是基础值，实战伤害受境界、装备、心法及属性影响。

## 局内规则

- 捡蓝色灵晶攒修为，升级后从三张卡中选一张。每局开场只有御剑术 Lv1，其他已在洞府领悟的功法才会进入抽卡池。
- 功法最多八格，普通功法最高 Lv5。适用的范围或射程在 Lv5 变为 ×1.3，适用的飞剑、雷击或召唤物数量 ×1.5 后向上取整。
- 两个功法位优先给新功法和已有功法升级，第三张为属性；满八格仅抽升级和属性。功法候选不足才由属性补位。非进化卡每张有 8% 概率为珍稀：功法加两级（仍封顶 Lv5），属性收益翻倍。
- 进化主功法必须 Lv5；若搭档是局内功法，只需习得，不必满级；若搭档是洞府心法，则必须点满。条件满足后下次升级保证出现一张进化金卡；若同时满足多条，从中抽一条。选中后两个局内功法合并成一格，心法作为条件则不会被消耗。

## 洞府心法和局内属性卡

| 洞府心法 | 满级 | 每级提升 |
|---|---:|---|
| 锻体诀 | 5 | 气血上限 +15 |
| 御灵诀 | 5 | 全伤害 +6% |
| 风行诀 | 3 | 移速 +4% |
| 聚宝诀 | 3 | 灵石掉落量 +10% |
| 凝神诀 | 3 | 冷却缩减 +4% |

八种普通属性卡：攻击强化（攻击 +5%）、气血强化（上限 +20）、身法强化（移速 +4%）、凝神（冷却缩减 +4%）、拾遗（拾取范围 +10%）、嗜血（击杀回血 +2）、聚宝（灵石掉落量 +8%）、铁壁（受伤减免 +3%）。属性卡不是进化搭档，不占功法槽。
