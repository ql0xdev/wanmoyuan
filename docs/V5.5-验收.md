## 未变化的规则

坐标只做 `原地面 X/Z → 2D X/Y` 1:1 转换；碰撞层、半径、速度、技能与掉落表都保留。摄像机覆盖区域改用 2D 投影计算画外生成和落雷候选，兽潮配比、时序、生成环计算没有改。怪物装备固定种子 4,000 次、3,205 件，指纹仍为 `bf54d2e15ff3eb55e98c36006eeb915d1d923ca86f568b90dbf8720e0cb6014e`。
