大境界倍率现为 **1 / 2 / 4 / 8 / 16 / 32**。仍按每小层 +8% 叠加，九层为同境界一层的 1.64 倍。下一境界一层的基础倍率是前一境界一层的两倍，所以同样装备、心法下，大突破的攻击倍率增幅为 `2 ÷ 1.64 − 1 ≈ 21.95%`，气血同理（面板对气血取整）。
